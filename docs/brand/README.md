# VN EDGE

Product name: **VN EDGE**. Tagline: **Trade with precision**.

The supplied blue, black and white artwork is retained in `source/`. The SVG symbol and outlined wordmark are geometric reconstructions of that artwork, not original vector source files. All exported files are generated by `ops/brand-assets.mjs`; keep that source in sync when changing the geometry.

## Assets

`dashboard/public/brand/` contains blue, white and black SVG/transparent PNG lockups, standalone SVG symbols, 32/192/512px icons, an Apple touch icon and a maskable icon. The standalone symbol is used in the sidebar, mobile header and bot feed. Full lockups and the tagline are reserved for sign-in, session loading and setup. Favicon and mobile icons use the white symbol on midnight navy, with extra safe-area padding for the maskable icon.

Generate SVGs with `node ops/brand-assets.mjs`. To regenerate PNGs, provide an installed Sharp module through `SHARP_MODULE` and run the same command with `--png`. Sharp is a build-time export tool only; it is not an application runtime dependency.

The logo gradient runs from cyan `#2ca9f4` to blue `#1878f2`. Use the darker action blue for white button labels. Green remains gain/long/success, red remains loss/short/danger, and amber remains attention. Paper, live and shadow labels retain their separate text and visual treatments. The chart's bot-owned entry annotations use blue; original scanner plots, author names and Vela credits remain intact.

Use Plus Jakarta Sans for interface text and headings, JetBrains Mono/tabular figures for prices, quantities and aligned numeric columns. Headings no longer use italic serif emphasis. Preserve compact density, current navigation and table structure.

## Scope

Branding applies to app chrome, authentication, browser metadata/icons, bot feed identity, bot-owned chart annotations and daily-report/test-alert templates. Internal IDs, URLs, environment variables, service names and persisted preferences continue using their existing identifiers. This change does not change scanners, account sizing, fee models, execution or risk policy. No notification test is sent as part of branding verification.
